How a round works

Eight tries. You start with a tenth of a second and unlock more with every wrong guess or skip:
0.1s → 0.5s → 1s → 2s → 4s → 7s → 11s → 16s
Start typing to search, then pick from the dropdown — a guess only counts if it matches a real track.
